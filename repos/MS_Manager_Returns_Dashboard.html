Dashboard Team Guide

Operational guidance for maintenance and distribution

Good Practice

AreaRecommended PracticeWhy
Source ControlVersion-control map files and scripts. Commit map updates and cache refresh updates together.Ensures reproducibility for any dashboard output.
Data RefreshRun the one-click refresh before major meetings, publication, or distribution.Avoids stale cache values across Post/Pre/Full/NMI tabs.
Map MaintenanceWhen onboarding managers, update SAA map files first, then refresh all caches.Dashboard universes are map-gated and update only after cache rebuild.
Quality ChecksSpot-check at least one manager per tab after each refresh, including Full splice transition months.Catches stream or mapping anomalies early.
DistributionShare the HTML with the matching cache JS files as a synchronized bundle.Prevents mismatched logic/data versions.

How To Refresh All Data

Preferred one-click refresh command (Windows):

MS/Refresh_All_Manager_Data.cmd

This runs: Post fetch, Pre fetch, cache copy to dashboard folder, Full history rebuild, and MSCI cache refresh.

What Files To Share With Team

For a viewer-only handoff (no local refresh), send this minimum bundle:
