New Manager Input – Formula Reference

All formulas used in the New Manager Input analytics page. Monthly returns are expressed as decimals (e.g. 0.02 = 2%).

Common Variables

SymbolDefinition
riManager monthly return in month i
biBenchmark monthly return in month i
eiExcess return = ri − bi
nNumber of monthly observations
wRolling window size (months), e.g. 36 for 3Y

1. Cumulative Return Index

Both manager and benchmark cumulative indices start at 100 and compound monthly.

Cumul0 = 100
Cumult = Cumult−1 × (1 + rt)

Benchmark index uses bi instead of ri. Where benchmark data is missing, return is treated as 0.

2. Annualised Return

Total Return = Cumuln / 100
Years = n / 12
Ann. Return = (Total Return1/Years − 1) × 100

3. Annualised Volatility

μ = (1/n) × Σ ri
σmonthly = √[ Σ(ri − μ)² / (n − 1) ]
Ann. Volatility = σmonthly × √12 × 100

Uses sample standard deviation (n−1 denominator).

4. Tracking Error

ē = (1/m) × Σ ei (where m = count of months with benchmark data)
σexcess = √[ Σ(ei − ē)² / (m − 1) ]
Tracking Error = σexcess × √12 × 100

Only months where benchmark data exists are included.

5. Information Ratio (Full Period)

IR = (ē × 12) / (Tracking Error / 100)

Annualised excess return divided by annualised tracking error.

6. Rolling Information Ratio

For each rolling window of w months ending at month t:
μw = mean(et−w+1 … et)
σw = sample std(et−w+1 … et)
IRt = (μw × √12) / (σw × √12)

Default window: 36 months. Additional windows can be added (12, 24, 48, 60).

7. Rolling Tracking Error

For each rolling window of w months ending at month t:
TEt = sample std(et−w+1 … et) × √12 × 100

Default window: 36 months.

8. Rolling 3Y Average Hit Rate

For each rolling 36-month window ending at month t:
Hit Ratet = (count of months where ei > 0) / (total months in window) × 100

Rolling 3Y Avg Hit Rate = mean of all Hit Ratet values

Windows with less than 80% benchmark coverage are excluded.

9. Rolling 3Y Average Information Ratio

Rolling 3Y Avg IR = mean of all rolling 36-month IRt values

Uses the same IR formula as Section 6 for each window.

10. Up/Down Capture Ratio (Summary Statistics)

Up Capture: Performance in months where benchmark was positive.

Compound Manager Up = Π(1 + ri) for all months where bi > 0
Compound Bmk Up = Π(1 + bi) for all months where bi > 0
Ann. Manager Up = Compound12/count − 1
Ann. Bmk Up = Compound12/count − 1
Up Capture = (Ann. Manager Up / Ann. Bmk Up) × 100

Down Capture: Same formula applied to months where bi < 0.

Requires at least 3 up/down months respectively.

11. Capture Ratio (Multi-Period Tile)

Uses sum-of-returns method for selectable periods (1Y, 3Y, 5Y, Inception).

Up Capture = (Σ ri for up months) / (Σ bi for up months) × 100
Down Capture = (Σ ri for down months) / (Σ bi for down months) × 100
Capture Ratio = Up Capture / Down Capture

Up months: bi ≥ 0. Down months: bi < 0. Ratio > 1× indicates favourable asymmetry.

12. Period Returns (YTD, 1Y, 3Y, 5Y, Since Inception)

Total Return = Cumulend / Cumulstart − 1

If period ≤ 12 months: Period Return = Total Return × 100
If period > 12 months: Annualised Return = [(1 + Total Return)1/years − 1] × 100

13. Cumulative Excess Return

Excess Cumult = Manager Cumult − Benchmark Cumult

Difference of cumulative return indices (both starting at 100).

14. Calendar Year Returns

For each calendar year Y:
Manager Year Return = [Π(1 + ri) − 1] × 100 for all months i in year Y
Benchmark Year Return = [Π(1 + bi) − 1] × 100 for all months i in year Y

Only full-year data or partial years at start/end of the series.

15. Quarterly Performance by Year (Excess Returns)

Q1 = Jan–Mar, Q2 = Apr–Jun, Q3 = Jul–Sep, Q4 = Oct–Dec

Qtr Manager Return = [Π(1 + ri) − 1] × 100 for months in quarter
Qtr Benchmark Return = [Π(1 + bi) − 1] × 100 for months in quarter
Qtr Excess = Qtr Manager − Qtr Benchmark

Only displayed for full quarters (3 months of data required).

16. Drawdown

Peakt = max(Cumul0 … Cumult)
Drawdownt = (Cumult − Peakt) / Peakt × 100

Shown for both manager and benchmark. Always ≤ 0%.

17. Snail Trail (3Y Active Risk vs 3Y Excess Return)

Scatter plot of rolling 36-month observations.

For each 36-month window ending at month t:

Excess Slice: ei = ri − bi for i in window
μexcess = mean(excess slice)
σexcess = sample std(excess slice)

X-axis (Active Risk) = σexcess × √12 × 100
Y-axis (Excess Return) = [(1 + μexcess)12 − 1] × 100

Points are plotted chronologically with older points more transparent. Trail line connects observations.

18. Quarterly Excess Return Distribution

Histogram of quarterly excess returns, split by rising/falling benchmark markets.

Qtr Excess = [Π(1 + ri) − 1] − [Π(1 + bi) − 1] (× 100, for months in quarter)

Rising Market: Qtr Benchmark Return ≥ 0
Falling Market: Qtr Benchmark Return < 0

Dynamic bin width: adapts based on data range (0.5% for narrow, up to 2%+ for wide spreads).

19. Benchmark Monthly Returns (from MSCI Index Levels)

Benchmark Returnt = (Levelt / Levelt−1) − 1

MSCI index data is stored as price levels. Monthly returns are derived by dividing consecutive levels. Dates are aligned to month-end.
